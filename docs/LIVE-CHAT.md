# 爱式塔自由交谈与本机 MCP

从 v1.1.0 开始，资料终端包含爱式塔自由交谈功能。进入存档，在原作爱式塔聊天窗口点击“自由交谈”，或按 **F9**，即可打字与模型交流。聊天区沿用原作窗口和对话记录列表，支持流式回复、展开工具详情、停止当前请求，以及发送新指令中断上一轮操作。

## API 设置

在原作设置中打开 **LLM** 页。API 地址、模型、Key、协议及所有模型参数都由玩家填写，没有预设服务或内置密钥。

LLM 与独立直播观众 Mod 的页签沿用原作边框、字体和选中样式，接在“音频”右侧；可用宽度不足时排到第二行。内容使用设置页的可用区域，超出部分通过原生像素滚动条阅读，保存与返回按钮保留在底部。

- 基础参数：Chat Completions / Responses、模型、Temperature、回复 Token 上限、连续工具调用轮数、超时，以及跟随原作人格或指定共情、技术、键政、媚俗人格。
- 高级参数：角色补充设定、其他请求参数 JSON、自定义请求头 JSON。未填写的模型采样参数沿用服务默认值；推理强度等服务专有字段也可在 JSON 中填写。
- 本机 MCP：启用开关、当前连接状态、复制 Codex 接入命令与通用客户端配置。
- 上下文：实际输入、输出、缓存 Token 用量，预计上下文大小，手动整理、自动整理阈值和近期完整回合数。

地址可填写 `https://服务地址/v1` 或完整接口地址。本地无密钥服务可留空 Key。Key 和自定义请求头使用当前 Windows 用户的 DPAPI 加密，配置保存在游戏目录下 `BepInEx/plugins/InfantGodArchive/livechat-data/llm-settings.json`。

## 游戏操作

模型通过游戏现有的界面事件和规则进行操作，包括读取窗口与长文本、点击和双击、右键、拖动、悬停、长按、填写文字、滚动、调整滑块和下拉框、继续对白和选择当前选项。因此邮件、网页、商店、直播、存档及其他通过原作电脑界面提供的操作，可以沿玩家使用的界面完成。

配装另有结构化工具：读取库存和布局、寻找合法协议位置、放置和取下协议、安装核心。工具遵守原作的物品拥有、摆放和卸载限制。资料查询使用当前存档的已探索范围。

UI 引用在一次观察中生成，界面操作后返回新的观察；后续操作使用新的引用。工具串行执行，取消会释放指针与长按状态。游戏内请求和外部 MCP 调用交接时，会先停止正在运行的请求，避免两个操作同时控制游戏。

**Esc** 或聊天区的“停止”可以取消当前操作。已完成的游戏动作仍按游戏自身规则保存。

## 上下文与缓存

未整理时，模型历史只追加，不改写已经发送的消息。角色说明、工具定义和已经发送的资料保持稳定；当前对白、存档状态等观察追加到本轮末尾。持久化会话 ID 和整理代数生成稳定的 `prompt_cache_key`，玩家在额外参数中显式填写的同名字段优先。

这是客户端对缓存前缀的保证；是否命中、保留多久和计费方式由所选服务决定。界面使用服务实际返回的 input/output/cached Token 值，未返回时显示“未返回”。自动整理判断中的 Token 数是估计值，不能视为精确分词结果。

自动整理阈值 `0` 表示关闭，可以手动点击“现在整理上下文”。整理过程先保存完整原记录，再请求结构化摘要。玩家原话和操作记录由程序保留，近期回合完整保留，工具调用与结果保持配对；较大历史结果带有稳定记录编号，模型可用 `search_conversation_history` 和 `read_conversation_record` 回查全文。

只有摘要有效且上下文确实缩小时才替换活动历史。请求失败、取消或无法继续缩小时，原上下文保留，并显示原因。若玩家原话、操作记录和近期回合已占主要篇幅，整理不会强行删掉这些内容。聊天和归档保存在 `livechat-data`，与原作剧情存档分开；切换存档后模型需要重新读取当前游戏状态。

## 接入 Codex 或其他客户端

先在 **设置 → LLM → 本机 MCP** 启用并保存，保持游戏运行。连接不要求填写游戏内 LLM API。

设置页可以复制适合当前安装路径的命令。默认 Steam 路径的示例：

```powershell
codex mcp add infantgod -- 'B:\Steam\steamapps\common\幼神 Demo\Build\BepInEx\plugins\InfantGodArchive\mcp\InfantGod.Mcp.exe'
```

通用 stdio 客户端配置：

```json
{
  "mcpServers": {
    "infantgod": {
      "command": "B:\\Steam\\steamapps\\common\\幼神 Demo\\Build\\BepInEx\\plugins\\InfantGodArchive\\mcp\\InfantGod.Mcp.exe",
      "args": []
    }
  }
}
```

外部客户端还可使用 `capture_game_view` 获取游戏自身渲染的 PNG。连接通过本机命名管道完成，游戏退出后不可执行操作；接口不监听网络端口。外部操作会记录到自由交谈窗口。

命令行也提供单次调用：

```powershell
& '.\InfantGod.Mcp.exe' --call get_game_state --output '.\game-state.json'
```

`--arguments` 接受一个 JSON 对象，`--plugin-dir` 可指定游戏插件目录。不传 `--call` 时按标准 stdio MCP 运行。工具失败返回非零退出码，原始结果仍可保存以便查看原因。

## 当前验证范围

实现已针对当前游戏程序集编译，并在隔离游戏副本进行设置入口与 MCP 联调。具体实机结果见本版发行说明。发行包没有内置实际 API 服务，因此真实模型回复、服务缓存命中和自动摘要效果需要玩家填写自己的服务后使用。
