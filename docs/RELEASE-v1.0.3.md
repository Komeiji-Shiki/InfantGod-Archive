# 幼神资料终端 v1.0.3

统一资料终端的滚动条样式。

- 主页面、左侧导航和详情窗口使用 12 像素宽的直角滚动条。
- 轨道使用终端的奶黄色，滑块使用深灰色，悬停和拖动时显示橙色。
- 移除突兀的系统白底箭头；滚轮、触控板和拖动滚动条的操作保持可用。
- 游戏内终端与单文件离线网页同步更新。

推荐下载 **InfantGod-Archive-Setup-v1.0.3.exe**，退出游戏后双击更新。安装器保留原文件备份、进度和配置。

`InfantGod-Archive-Mod-v1.0.3.zip` 是手动安装包，`InfantGod-Archive.html` 是离线网页，`InfantGod-Archive-Source-v1.0.3.zip` 是本版源码。完整安装包应安装到 `Aistalt.exe` 所在目录，不能把外层文件夹直接放入 `StreamingAssets/Mods`。

本版保留 v1.0.2 的已探索场景命名、存档状态显示和失焦页面预览功能。
