# 幼神资料终端 v1.0.2

修复已探索模式中的场景定位、当前存档结果，以及游戏内窗口失焦后空白的问题。

- 已探索场景使用明确的话题名称、共同开场或能够确认的进入选项，不再整页显示相同的“已到达的对话场景”。菲利克斯的列车对话按去向、行李、小说、战争、逃亡方案和到站前谈话分别命名。
- 已探索分支页新增按话题或对话开头查找场景；导航、概览和搜索提示明确当前范围。变量初始化记录不再作为看过人物剧情的依据，也不计入人物的已探索场景数。
- 关键路线页显示“当前存档进度”。哈基米德的调查进度、保留、合并和已完成处置按存档判断，憎恨核心也会区分轮盘赌来源。存档没有记录具体选项时，会明确说明无法区分，不用“晚点再决定”等攻略提示代替实际结果。
- 资料终端失焦后保留最后一帧页面，由游戏按原生窗口层级绘制；其他窗口可以正确遮挡它。重新点回资料终端时恢复可交互网页。

推荐下载 **InfantGod-Archive-Setup-v1.0.2.exe**，退出游戏后双击更新。安装器继续使用游戏的像素风格，保留原文件备份、进度和配置。

其他文件：`InfantGod-Archive-Mod-v1.0.2.zip` 为手动安装包，`InfantGod-Archive.html` 为离线资料页，`InfantGod-Archive-Source-v1.0.2.zip` 为完整源码。

安装完成后，在游戏设置的 Mod 管理器中启用资料终端，按 F8 打开。完整安装包文件夹不能直接放入 `StreamingAssets/Mods`，请使用安装器或将包内文件合并到 `Aistalt.exe` 所在目录。
