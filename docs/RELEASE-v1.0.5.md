# 幼神资料终端 v1.0.5

资料终端的主菜单入口改为与“新游戏”“载入游戏”“设置”相同的原生按钮，放在“设置”和“离开”之间。进入其他页面后随主菜单隐藏，游戏内继续使用桌面的资料终端图标。

移除右上角的悬浮入口，并避免在主菜单阶段提前创建游戏电脑 UI 资源。原资料查询、已探索范围和独立网页窗口保持原有功能。

推荐下载 **InfantGod-Archive-Setup-v1.0.5.exe**，退出游戏后双击更新。其他文件：`InfantGod-Archive-Mod-v1.0.5.zip` 为手动安装包，`InfantGod-Archive.html` 为离线资料页，`InfantGod-Archive-Source-v1.0.5.zip` 为完整源码。
