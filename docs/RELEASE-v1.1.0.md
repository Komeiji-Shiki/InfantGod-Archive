# 幼神资料终端 v1.1.0 · 爱式塔自由交谈与本机 MCP

原作爱式塔聊天窗口现在支持打字交流与工具调用。在设置的 **LLM** 新页填写自己的 API，进入存档后按 **F9** 打开自由交谈。

- 支持流式 Chat Completions 与 Responses，以及玩家填写的模型参数、请求头和四人格设定。
- 模型可以读取游戏电脑、点击、双击、右键、拖动、悬停、长按、填写文字、滚动、调整控件、继续对白和操作配装。执行遵循原作条件与结算。
- 本机 stdio MCP 向 Codex 和其他客户端开放同一组操作，另提供游戏画面截图。游戏设置可以复制接入命令与配置。
- 上下文未整理时保持历史追加和缓存前缀稳定；整理前保存全文，保留玩家原话、操作记录和近期回合，并支持按记录编号回查历史。
- 输入、输出与缓存 Token 使用服务实际返回值，自动整理阈值使用估计值。摘要失败或不能缩小时保留原上下文。
- 设置页直接复用原作页签，充分使用“音频”右侧空间；窄窗口换到第二行，内容区展开并使用原生像素滚动条。

聊天区有停止、新对话和工具详情。发送新指令会取消旧请求；外部 MCP 接管时同样按顺序交接操作。

API Key 与自定义请求头在本地使用 Windows DPAPI 加密。模型地址、模型 ID 和打字交流的 API 均由玩家自行配置。

完整说明见 [自由交谈与 MCP](https://github.com/Komeiji-Shiki/InfantGod-Archive/blob/main/docs/LIVE-CHAT.md)。原有资料终端继续通过 **F8** 使用。

## 下载与升级

- **InfantGod-Archive-Setup-v1.1.0.exe**：自包含图形安装器，关闭游戏后运行即可升级。
- **InfantGod-Archive-Mod-v1.1.0.zip**：手动安装包与安装、卸载脚本。
- **InfantGod-Archive-Source-v1.1.0.zip**：本版本源码。
- **InfantGod-Archive.html**：单文件离线资料页。

此安装包包含资料终端、自由交谈和 MCP。直播观众和第八天以后是独立项目，分别安装和配置。

## 验证

已针对当前 Demo 游戏程序集完成编译。隔离副本确认资料终端、直播观众、第八天以后三个插件共同加载，本机 MCP 能读取真实主菜单与设置控件，并导出游戏画面。

实机点击发现 FairyGUI 自定义输入会在每帧结束后重置，已据原版实现修正命中判断和持续按住逻辑；同时修正两个新增设置入口与右上角资料按钮重叠的问题。用户按 Escape 停止界面操作后，未继续实机复验这两项。真实 API、服务缓存命中、摘要效果及完整游戏操作链尚未验证。
