# 幼神资料终端 v1.0.4

修复更新到 v1.0.2 / v1.0.3 后，资料终端失焦或被其他游戏窗口遮挡时仍然空白的问题。

上一版可以正常生成页面截图，但预览图被放在原生窗口外框的不透明底板下方，因此实际显示仍是空白。现在将预览放到该底板上层，并保持在正文区域内，标题栏和其他原生窗口的层级不变。

推荐下载 **InfantGod-Archive-Setup-v1.0.4.exe**，退出游戏后双击更新。本次修复包含游戏插件，需要重新启动游戏加载新版。

其他文件：`InfantGod-Archive-Mod-v1.0.4.zip` 为手动安装包，`InfantGod-Archive.html` 为离线资料页，`InfantGod-Archive-Source-v1.0.4.zip` 为完整源码。

本版保留已探索模式的场景命名、存档状态、场景搜索和像素风滚动条。
